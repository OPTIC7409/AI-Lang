# Cogito for Visual Studio Code

Syntax highlighting for [Cogito](../../README.md) (`.cog` files): keywords,
contracts, tests, string interpolation, raw and triple-quoted strings,
numbers and operators.

To install locally, copy or symlink this folder into your VS Code extensions
directory and reload the window:

```console
$ ln -s "$(pwd)" ~/.vscode/extensions/cogito-lang
```
