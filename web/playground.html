Run executes the program. Test runs its test and property blocks, generating random inputs for properties. Verify checks every function's requires/ensures contracts against generated inputs and shrinks any failure to a small counterexample. Fix rewrites habits from other languages (&&, null, xs.length(), elif) into Cogito.

    
In the browser, programs cannot read files or import modules, recursion stops at 300 nested calls, and a run stops after 40 million steps. The cogito command-line tool has none of these limits.

    
Error codes such as E0200 are explained in detail by cogito explain E0200. The full language fits in one compact specification, written so that a language model can learn it from a single read.
